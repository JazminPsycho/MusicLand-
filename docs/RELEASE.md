# JAPs Música v0.1.0 · prototipo local

Biblioteca local en español, importación WAV PCM a MP3, reproductor persistente, aprobación/revocación de cuentas, métricas iniciales y herramientas de copia/restauración. Incluye tres muestras sintetizadas originales.

Requisitos y arranque: ver README.md. Datos privados fuera del paquete. Sin contraseña inicial predeterminada.

Evidencia: 13 pruebas automatizadas, incluidas conversión FFmpeg y restauración verificable; repetidas desde el ZIP en una carpeta nueva con espacios. No hay evidencia de interfaz visual, sonido, Safari ni carga prolongada. Ver docs/pruebas.md y docs/estado.md para limitaciones y continuidad. No habilitar internet con esta entrega.
